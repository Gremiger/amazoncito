# amazon-ar Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Extensión MV3 para amazon.com que, con entrega a Argentina, muestra el costo total (precio + envío + importación) en listados, ficha y carrito, su equivalente en ARS con percepciones (perfil Río Cuarto, Córdoba) y destaca el envío gratis desde USD 99.

**Architecture:** Lógica pura en `lib/` (ES modules, testeados con `node --test` + `linkedom` sobre fixtures reales). Un único content script clásico (`content/boot.js`) importa dinámicamente `content/main.js`, que enruta a listing/product/cart. Los fetch de fichas `/dp/ASIN` y su parseo ocurren en el content script (tiene `DOMParser` y cookies same-origin); el service worker solo da cotizaciones de dolarapi.com y poda la caché.

**Tech Stack:** JavaScript plano (ES2022), Chrome Extension Manifest V3, Node ≥ 20 (`node --test`), `linkedom` (devDependency).

**Spec:** `docs/superpowers/specs/2026-10-09-amazon-ar-design.md`

## Global Constraints

- Solo `https://www.amazon.com/*`; la extensión no hace nada si `#glow-ingress-line2` no contiene "Argentina".
- Sin build ni bundler; se carga como "unpacked" en Arc.
- Única dependencia: `linkedom` (dev). Nada en runtime.
- Dato principal en USD; ARS visible por defecto (`mostrarArs: true`), rotulado "(Córdoba)".
- Defaults: `percepcionGanancias: 30`, `percepcionIibb: 0`, `concurrencia: 3`, `modoListado: "auto"`.
- Caché de fichas: 24 h en `chrome.storage.local`, clave `fee:{ASIN}`. Cotización: 1 h, clave `rates`.
- Fetch de ficha: timeout 15 s, 1 reintento. Captcha → pausa de cola 5 min.
- Umbral envío gratis: USD 99.
- Montos: USD con 2 decimales formato es-AR (`USD 503,00`); ARS sin decimales (`ARS 774.620`).
- Textos de UI en español rioplatense.
- Commits sin trailer `Co-Authored-By`.

## Review Focus

- Montos con separador de miles (`$1,234.56`, `ARS 589,918.50`) → deben parsear a 1234.56 / 589918.5, no a 1.
- Ficha sin popover (no envía a Argentina, o markup cambiado) → `parseFeeDetails` devuelve `null` y el badge cae a "No envía a Argentina" / "Ver total", nunca a "USD NaN".
- Moneda de Amazon en ARS → badge "Cambiá la moneda de Amazon a USD", sin convertir.
- dolarapi.com caído → se usa la última cotización guardada (con fecha) o se omite la línea ARS; el total USD se sigue mostrando.
- Resultados cargados después (scroll / paginación AJAX / filtros) → también reciben badge, y ninguna tarjeta recibe dos badges.

`lib/money.js`:
```js
// Amazon usa formato en-US en montos aun con UI en español: "1,234.56".
export function parseMoney(text) {
  if (!text) return null;
  const t = String(text).replace(/ /g, " ").trim();
  const num = t.match(/\d[\d,]*(?:\.\d+)?/);
  if (!num) return null;
  const currency = /ARS/i.test(t) ? "ARS" : "USD";
  return { amount: Number(num[0].replace(/,/g, "")), currency };
}
```

`lib/parse.js`:
```js
import { parseMoney } from "./money.js";

const ROWS = [
  ["price", /^(price|precio)/i],
  ["shipping", /(shipping|env[ií]o)/i],
  ["importCharges", /(import)/i],
  ["total", /^total/i],
];

const text = (el) => (el?.textContent ?? "").replace(/\s+/g, " ").trim();

export function parseFeeDetails(doc) {
  const table = doc.querySelector('[id^="a-popover-"] table.a-lineitem');
  if (!table) return null;
  const out = {};
  let currency = null;
  for (const tr of table.querySelectorAll("tr")) {
    const tds = tr.querySelectorAll("td");
    if (tds.length < 2) continue;
    const label = text(tds[0]);
    const money = parseMoney(text(tds[tds.length - 1]));
    if (!label || !money) continue;
    const row = ROWS.find(([, re]) => re.test(label));
    if (!row || row[0] in out) continue;
    out[row[0]] = money.amount;
    currency ??= money.currency;
  }
  if (out.price == null) return null;
  const shipping = out.shipping ?? 0;
  const importCharges = out.importCharges ?? 0;
  const total = out.total ?? Math.round((out.price + shipping + importCharges) * 100) / 100;
  return { price: out.price, shipping, importCharges, total, currency };
}

const bodyText = (doc) => doc.body?.textContent ?? "";

export function isNoShip(doc) {
  return /cannot be shipped to your selected delivery location|no se puede enviar a la ubicaci[oó]n/i.test(bodyText(doc));
}

export function isCaptcha(doc) {
  return !!doc.querySelector('form[action*="validateCaptcha"]') ||
    /Enter the characters you see below|Introduce los caracteres que ves/i.test(bodyText(doc));
}

export const FREE_99_RE = /(over|m[aá]s de|superiores a)\s*(US)?\$\s?99\b|\$99 of eligible/i;

export function parseFreeShippingEligible(doc) {
  const block = doc.querySelector("#mir-layout-DELIVERY_BLOCK, #deliveryBlockMessage");
  return FREE_99_RE.test(text(block));
}
```

```js
const CARD_SELECTOR = [
  '[data-component-type="s-search-result"][data-asin]',
  'div[data-asin]:not([data-asin=""])',
].join(",");

export function findCards(root) {
  const all = [...root.querySelectorAll(CARD_SELECTOR)].filter(
    (el) => el.getAttribute("data-asin") && el.querySelector(".a-price") && el.querySelector('a[href*="/dp/"]'),
  );

export function parseListingCard(el) {
  return {
    asin: el.getAttribute("data-asin"),
    price: parseMoney(text(el.querySelector(".a-price .a-offscreen"))),
    freeEligible: FREE_99_RE.test(text(el.querySelector('[data-cy="delivery-recipe"]')) || text(el)),
```

`lib/calc.js`:
```js
export const FREE_THRESHOLD = 99;
const r2 = (n) => Math.round(n * 100) / 100;

export function arsBreakdown(usd, oficialVenta, { percepcionGanancias, percepcionIibb }) {
  const base = usd * oficialVenta;
  const oficial = Math.round(base);
  const ganancias = Math.round((base * percepcionGanancias) / 100);
  const iibb = Math.round((base * percepcionIibb) / 100);
  return { oficial, ganancias, iibb, total: oficial + ganancias + iibb };
}

export const freeShippingTotal = (fee) => r2(fee.total - fee.shipping);

export const freeShippingGap = (subtotalUsd, threshold = FREE_THRESHOLD) =>
  Math.max(0, r2(threshold - subtotalUsd));
```

```js
const usd = new Intl.NumberFormat("es-AR", { minimumFractionDigits: 2, maximumFractionDigits: 2 });
const ars = new Intl.NumberFormat("es-AR", { maximumFractionDigits: 0 });

export const fmtUsd = (n) => `USD ${usd.format(n)}`;
```

```js
export const DEFAULTS = Object.freeze({
  mostrarArs: true,
  perfil: "Córdoba",
  percepcionGanancias: 30,
  percepcionIibb: 0,
  concurrencia: 3,
  modoListado: "auto", // "auto" | "hover"

export function mergeSettings(stored) {
  const out = { ...DEFAULTS };
  for (const k of Object.keys(DEFAULTS)) if (stored && k in stored) out[k] = stored[k];
  return out;
}
```

```js
export function createQueue({ concurrency }) {
  const inflight = new Map();
  const waiting = [];
  let active = 0;
  let pausedUntil = 0;

  const pump = () => {
    while (active < concurrency && waiting.length) {
      const delay = pausedUntil - Date.now();
      if (delay > 0) { setTimeout(pump, delay); return; }
      const { fn, resolve, reject } = waiting.shift();
      active++;
      fn().then(resolve, reject).finally(() => { active--; pump(); });
    }
  };

  return {
    run(key, fn) {
      if (inflight.has(key)) return inflight.get(key);
      const p = new Promise((resolve, reject) => waiting.push({ fn, resolve, reject }))
        .finally(() => inflight.delete(key));
      inflight.set(key, p);
      pump();
      return p;
    },
    pause(ms) { pausedUntil = Math.max(pausedUntil, Date.now() + ms); },
    get pausedUntil() { return pausedUntil; },
  };
}
```

```js
import { parseFeeDetails, isNoShip, isCaptcha, parseFreeShippingEligible } from "../lib/parse.js";
import { createQueue } from "../lib/queue.js";
import { feeKey, isFresh, FEE_TTL_MS } from "../lib/cache.js";
import { localGet, localSet } from "./store.js";

const CAPTCHA_PAUSE_MS = 5 * 60 * 1000;
let queue = null;

export function resultFromDoc(doc) {
  if (isCaptcha(doc)) return { status: "captcha" };
  const fee = parseFeeDetails(doc);
  if (fee) return { status: "ok", fee, eligible: parseFreeShippingEligible(doc) };
  if (isNoShip(doc)) return { status: "noship" };
  return { status: "unknown" };
}

async function fetchDoc(asin) {
  let lastErr;
  for (let i = 0; i < 2; i++) {
    try {
      const res = await fetch(`/dp/${asin}`, { credentials: "include", signal: AbortSignal.timeout(15_000) });
      return new DOMParser().parseFromString(await res.text(), "text/html");
    } catch (e) { lastErr = e; }
  }
  throw lastErr;
}

export async function putFee(asin, result) {
  if (result.status === "ok" || result.status === "noship") await localSet(feeKey(asin), { at: Date.now(), result });
}

export async function getFee(asin, { concurrencia }) {
  const cached = await localGet(feeKey(asin));
  if (isFresh(cached, Date.now(), FEE_TTL_MS)) return cached.result;
  queue ??= createQueue({ concurrency: concurrencia });
  if (queue.pausedUntil > Date.now()) return { status: "captcha" };
  return queue.run(asin, async () => {
    const result = resultFromDoc(await fetchDoc(asin));
    if (result.status === "captcha") queue.pause(CAPTCHA_PAUSE_MS);
    await putFee(asin, result);
    return result;
  });
}
```

```js
import { resultFromDoc, putFee } from "./fetcher.js";
import { renderBadge } from "./badge.js";
import { getSettings, setSetting, getRates } from "./store.js";
import { freeShippingGap } from "../lib/calc.js";
import { fmtUsd } from "../lib/format.js";

const ANCHORS = ["#corePriceDisplay_desktop_feature_div", "#corePrice_feature_div", "#apex_desktop", "#price"];

export default async function runProduct() {
  const asin = document.querySelector("#ASIN, input[name='ASIN']")?.value ?? location.pathname.match(/\/(?:dp|product)\/([A-Z0-9]{10})/)?.[1];
  const result = resultFromDoc(document);
  if (result.status !== "ok") return; // Amazon ya muestra "no envía"; nada que agregar
  if (asin) await putFee(asin, result);
  const settings = await getSettings();
  const rates = await getRates().catch(() => null);
  const ctx = {
    settings, rates, variant: "box",
    onToggleArs: async (v) => { await setSetting("mostrarArs", v); location.reload(); },
  };
  const box = renderBadge(document, { ...result, asin }, ctx);
  if (result.eligible && result.fee.price < 99) {
    const p = document.createElement("div");
    p.className = "amzar-muted";
    p.textContent = `Con este ítem te faltan ${fmtUsd(freeShippingGap(result.fee.price))} en ítems elegibles para envío gratis.`;
    box.append(p);
  }
  const anchor = ANCHORS.map((s) => document.querySelector(s)).find(Boolean);
  (anchor ?? document.querySelector("#centerCol") ?? document.body).after(box);
}
```

```js
export function parseCart(doc) {
  const scope = doc.querySelector("#sc-active-cart") ?? doc;
  return [...scope.querySelectorAll("[data-asin][data-quantity]")]
    .filter((el) => el.getAttribute("data-asin"))
    .map((el) => {
      const attr = el.getAttribute("data-price");
      const price = attr ? Number(attr) : parseMoney(text(el.querySelector(".sc-product-price, .a-price .a-offscreen")))?.amount ?? null;
      return { asin: el.getAttribute("data-asin"), qty: Number(el.getAttribute("data-quantity")) || 1, price };
    });
}
```

```js
import { parseCart } from "../lib/parse.js";
import { getFee } from "./fetcher.js";
import { getSettings, getRates } from "./store.js";
import { freeShippingGap, arsBreakdown, FREE_THRESHOLD } from "../lib/calc.js";
import { fmtUsd, fmtArs } from "../lib/format.js";

const ANCHORS = ["#sc-buy-box", "#gutterCartViewForm", "#sc-active-cart"];

export default async function runCart() {
  const settings = await getSettings();
  const rates = await getRates().catch(() => null);
  const box = document.createElement("div");
  box.className = "amzar amzar-box";
  box.dataset.amzarBadge = "1";
  (ANCHORS.map((s) => document.querySelector(s)).find(Boolean) ?? document.body).prepend(box);

  const render = async () => {
    box.textContent = "Calculando total a AR…";
    const items = parseCart(document);
    const results = await Promise.all(items.map((i) => getFee(i.asin, settings).catch(() => ({ status: "error" }))));
    let eligibleSubtotal = 0, total = 0, missing = 0, eligibleShipping = 0;
    items.forEach((it, idx) => {
      const r = results[idx];
      if (r.status !== "ok" || r.fee.currency !== "USD") { missing++; return; }
      total += r.fee.total * it.qty;
      if (r.eligible) { eligibleSubtotal += (it.price ?? r.fee.price) * it.qty; eligibleShipping += r.fee.shipping * it.qty; }
    });
    const reached = eligibleSubtotal >= FREE_THRESHOLD;
    if (reached) total -= eligibleShipping;
    box.textContent = "";
    const head = document.createElement("div");
    head.className = "amzar-total";
    head.textContent = reached
      ? "Envío gratis alcanzado ✓"
      : `Te faltan ${fmtUsd(freeShippingGap(eligibleSubtotal))} en ítems elegibles para envío gratis`;
    const bar = document.createElement("div");
    bar.className = "amzar-progress";
    const fill = document.createElement("div");
    fill.style.width = `${Math.min(100, (eligibleSubtotal / FREE_THRESHOLD) * 100)}%`;
    bar.append(fill);
    const tot = document.createElement("div");
    tot.className = "amzar-total";
    tot.textContent = `Total estimado a AR: ${fmtUsd(total)}`;
    box.append(head, bar, tot);
    if (settings.mostrarArs && rates) {
      const ars = document.createElement("div");
      ars.className = "amzar-ars";
      ars.textContent = `En pesos (${settings.perfil}): ${fmtArs(arsBreakdown(total, rates.venta, settings).total)}`;
      box.append(ars);
    }
    const note = document.createElement("div");
    note.className = "amzar-muted";
    note.textContent = "Estimado: Amazon recalcula envío e importación en el checkout." + (missing ? ` ${missing} ítem(s) sin dato.` : "");
    box.append(note);
  };

  await render();
  // El carrito se actualiza por AJAX al cambiar cantidades.
  const cart = document.querySelector("#sc-active-cart");
  if (cart) {
    let t;
    new MutationObserver(() => { clearTimeout(t); t = setTimeout(render, 600); })
      .observe(cart, { childList: true, subtree: true, attributes: true, attributeFilter: ["data-quantity"] });
  }
}
```
